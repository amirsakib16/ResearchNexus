# ResearchNexus: A Comprehensive Platform for Academic Mastery

ResearchNexus is a specialized platform designed to streamline academic research and thesis management for students and supervisors. Built with a modern JavaScript stack, it integrates productivity tracking, automated feedback, and AI-driven research tools.

## Tech Stack
* **Language:** JavaScript
* **Framework:** Node.js and Express, React Vite
* **Styling:** CSS
* **Database:** MongoDB Atlas
* **ORM:** None

---

## Key Modules & Features

### Module 1: Research & Supervision
* **Document Management:** Create folders, upload documents, and manage access requests (Public/Private).
* **Progress Tracking:** Weekly plans featuring visual progress bars for task completion.
* **NLP Feedback:** Automated filtering of supervisor feedback using Natural Language Processing.
* **Announcements:** Dedicated channels for weekly updates and planning.

### Module 2: Dashboard & Monitoring
* **Main Dashboard:** Centralized hub for student and supervisor activity.
* **Alert System:** Real-time notifications for deadlines (p1, p2, p3) and document updates.
* **Leadership Board:** Ranked productivity tracking based on daily user metrics.

### Module 3: Productivity Tools
* **Profile Management:** Customizable user profiles.
* **Interactive Reading:** Side-by-side notepad for taking notes while reading documents.
* **Favorites:** Ability to pin and unpin favorite research papers.
* **Daily Productivity:** Weekly tracking of user productivity levels.

### Module 4: AI & Data Security
* **AI Research Summarizer:** Automatically generates abstract-style summaries for uploaded papers.
* **Point System:** Earn points through paper searches to unlock AI features.
* **Data Safety:** Scheduled automated backups and manual restore via MongoDB collections.
